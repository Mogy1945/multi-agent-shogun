## 新機能 (Phase 4)

### ① パス先を選手選択
パスをクリック → 全10味方リストが表示

```
⚽ パス先選択（クリックで決定）
山田(GK)    9.0m  34%
中村(CM)    2.2m  55%  ← 近くて確率高い
木村(FW)    4.2m  38%
...
```
距離が近く、パスライン上に敵が少ないほど確率UP。クリックした瞬間に確定。

### ② 毎ターン全選手移動
各ターン後、22人全員が戦術ポジションへ自動移動。
- 攻撃チーム: FWはゴール前へ、MFはボール周辺へ
- 守備チーム: 自陣ゴール前に収束してブロック
- 数ターン経過すると選手が大きく動くのが分かる

### ③ 専任モード: 毎ターン移動
どの選手を選んでも毎ターン移動できる（GK/CB/FW 全部同じ）

```
🏃 移動フェーズ — 山田（GK）
現在位置: (1, 6)

         [↑ 上]
[← 後退] [現在] [→ 前進]
         [↓ 下]
[● 待機]
```

- ボールを持っていない時でも毎ターン行動できる
- ボールが来た時は通常の攻撃UI（パス/ドリブル/シュート）

### ④ 広いグリッドピッチ
フィールドが 20×12マスに拡張（以前の16×10より広い）。
グリッド線で「マス」を意識できる。距離もマス数で表示。

## 基本ルール (Phase 1-3から継続)

### 攻撃フェーズ
- **パス → 選手選択**: 10人から確率を見て選択
- **ドリブル**: 前進2マス (成功率中)
- **シュート**: ゴール距離で変動

### 個人スキル (Phase 3から)
- **ロングシュート★** (FW): 距離関係なくシュート
- **フェイント★** (FW/RM): 強化ドリブル
- **スルーパス★** (CM): 最前線への直接パス
- **ロングキック★** (GK): 遠方FWへ送球
- **インターセプト★** (CB/RB/LB): 強力守備奪取

### 守備フェーズ
タックル(バランス) / スライディング(強攻) / マーク(安全) / インターセプト★

## パス確率の読み方

| 状況 | 確率への影響 |
|------|------------|
| パス先が近い | 距離-5%/マス で上昇 |
| パスライン上に敵 | -18%/人 で低下 |
| 守備選手のタックル | ×0.68 |
| マーク継続効果 | -15% ペナルティ |
