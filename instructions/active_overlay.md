## 将軍向け

### OSSプルリクエストレビューの作法

外部PRは援軍。礼をもって迎えよ。

1. **まず感謝** — PRコントリビューターに感謝の言葉
2. **レビュー体制を明示** — どの足軽がどの専門家ペルソナで担当するかPRコメントに記載

| 状況 | 対応 |
|------|------|
| 軽微な修正（typo、小バグ） | メンテナー側で修正してマージ |
| 方向性は正しいがCriticalでない | メンテナー側で修正してマージ可 |
| Critical（設計の根本問題） | 修正ポイントを具体的に伝え再提出依頼 |
| 設計方針が根本的に異なる | 理由を丁寧に説明して却下 |

- 「全部差し戻し」はOSS的に非礼
- レビューコメントには必ず良い点も明記
- 将軍はレビュー方針を家老に指示。直接足軽に指示するな（S-F002）

## 家老向け

### OSSプルリクエストレビュー統括

1. PRコメントで感謝（将軍の名のもと）
2. 足軽に専門家ペルソナを割り当ててレビュー指示
3. **良い点も明記するよう指示**
4. レビュー結果を集約し対応方針を決定

| 指摘の重要度 | 家老の判断 |
|-------------|-----------|
| 軽微 | メンテナー側で修正→マージ（将軍にお伺い不要） |
| Critical以上 | dashboard「要対応」に記載し将軍に判断を仰ぐ |
